# SKU — IoTextra Relay

```
040201vvvr01
```

| Field | Description |
|---|---|
| `040201` | Product code — IoTextra Relay |
| `vvv` | Version (e.g. 302 = version 3.02) |
| `r` | SPST relay model (the latching relays are always KEMET EC2-5SNU) |
| `01` | Fixed suffix |

**SPST relay model (r):**

| Value | Description |
|---|---|
| 1 | HF49FD |
| 2 | APAN3105 |
