# SKU — IoTextra Octal3

| Field | Description |
|---|---|
| `040304` | Product code — IoTextra Octal3 |
| `vvv` | Version (e.g. 302 = version 3.02) |
| `cc` | Communication |

**Communication (cc):**

| Value | Description |
|---|---|
| 09 | HOST-12 connector |
